# GitDeck — 产品设计文档

## 一、产品定位

一款参考 Cursor Git Graph 的极简桌面 Git 管理工具。

支持 macOS、Windows，重点是**操作简单、界面精致、多仓库统一管理**。

## 二、核心功能

### 1. 项目管理

- 一个项目可以添加多个文件夹。
- 一个文件夹可以包含多个 Git 仓库。
- 自动识别仓库，支持快速切换。
- 项目配置本地保存。

### 2. Git Graph

- 可视化展示提交历史、分支和合并关系。
- 查看本地分支、远程分支和 Tag。
- 每个提交行右侧对齐展示该 Commit 的引用标签（Refs）：本地分支、远程分支与 Tag。
  - 颜色用于区分不同分支，不固定代表本地或远程；本地 / 远程以图标区分（远程分支使用云朵图标）。
  - 点击引用标签可查看分支信息、切换分支等。
- 支持分支筛选、创建、切换、合并和删除。
- 点击 Commit 查看修改记录和 Diff。

### 3. Changes

- 展示新增、修改、删除的文件。
- 查看 Diff、暂存、取消暂存、丢弃修改。
- 输入 Commit Message。
- 参考 Cursor 的提交下拉按钮：
  - 提交
  - 提交（修改）
  - 提交和推送
  - 提交和同步
- 支持 Fetch、Pull、Push。

## 三、界面设计

采用极简双栏布局：

- **左侧**：项目、文件夹、Git 仓库。
- **右侧**：Graph / Changes 两个视图切换。

视觉参考 Cursor：深色主题、紧凑布局、彩色分支线条、精细图标，不增加多余面板。

> 界面细节与原型转写见 [界面设计说明](ui-design.md)。

## 四、技术方案

| 模块 | 技术 |
|---|---|
| 桌面端 | Tauri 2 |
| 前端 | React + TypeScript |
| UI | Tailwind CSS + Lucide |
| Git | Git CLI |
| 图谱 | SVG + 虚拟列表 |
| 本地配置 | JSON |

## 五、开发顺序

1. **项目管理**：项目、文件夹、仓库识别。
2. **Git Graph**：提交历史、分支可视化及操作。
3. **Changes**：文件变更、Diff、暂存、提交。
4. **远程同步**：Fetch、Pull、Push。

**最终目标：只做项目管理、Git Graph、Changes 三个核心模块，尽可能还原 Cursor 的使用体验。**
